# Chi suona il basso?

Pagina web che riconosce un brano dal microfono (AudD, ACRCloud, Shazam via RapidAPI) oppure parte da titolo e autore, e cerca chi suona il basso su Discogs, MusicBrainz, Wikipedia (it, en, fr, de, es) e Google tramite Gemini. Raggruppa i crediti per nome, distingue credito del brano, credito del disco e deduzione dalla formazione, e mostra quali fonti hanno risposto.

Nessuna chiave è contenuta nel codice. Si inseriscono nel pannello "Chiavi e fonti" e restano nel browser; il pulsante "Copia link di configurazione" genera un link che configura un altro dispositivo. Il link contiene le chiavi: non va pubblicato.

Lo storico delle ricerche è salvato nel browser e si può esportare e reimportare come file JSON.
